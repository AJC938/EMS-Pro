# EMS Pro — Project Vision

## 1. Project Overview

EMS Pro is an enterprise Employee Management System implemented in Java 17.
The system follows a layered architecture and is built using Maven, with
SQLite as the data store accessed through JDBC. This document defines the
vision for the project as established by the current specification. It does
not define detailed features, data models, or implementation details, which
